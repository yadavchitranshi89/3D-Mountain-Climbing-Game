\# 🏔️ 3D Mountain Climbing Adventure



A 3D mountain climbing adventure game developed using Python and the Ursina Game Engine.



\## 🎮 About the Game



The player must climb different mountains by jumping across platforms and reaching the summit.



The game contains three difficulty levels:



\- 🟢 Level 1 – Beginner Mountain (Easy)

\- 🟡 Level 2 – Rocky Mountain (Medium)

\- 🔴 Level 3 – Extreme Summit (Hard)



Each completed level unlocks the next challenge.



\## ✨ Features



\- 🎮 First-person 3D gameplay

\- 🏔️ Three mountain levels

\- 🔓 Level unlocking system

\- ❤️ Three lives

\- 💀 Game Over system

\- 🏆 Level completion screen

\- 🔄 Restart level

\- 📋 Main Menu

\- 🎯 Level Selection

\- 🌳 Trees and mountain environment

\- ⌨️ Keyboard controls



\## 🕹️ Controls



| Key | Action |

|-----|--------|

| W | Move Forward |

| S | Move Backward |

| A | Move Left |

| D | Move Right |

| SPACE | Jump |

| R | Restart Level |

| M | Main Menu |

| ESC | Exit Game |

\- Python

\- Ursina Engine

▶️ How to Run

1\. Install Python



Make sure Python is installed on your computer.



2\. Install Ursina



Open Command Prompt or PowerShell and run:



pip install ursina

3\. Clone the Repository

git clone https://github.com/yadavchitranshi89/3D-Mountain-Climbing-Game.git

4\. Open the Project

cd 3D-Mountain-Climbing-Game

5\. Run the Game

python main.py

🎯 Objective



Reach the summit of all three mountains while avoiding falls and managing your three lives.



Complete each mountain to unlock the next level and ultimately conquer all three mountains.
